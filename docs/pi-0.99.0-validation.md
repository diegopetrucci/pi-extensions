## Implemented baseline changes

- Root `devDependencies` now declare all three Pi packages together as `^0.99.0`; `package-lock.json` resolves each direct package to exactly `0.99.0`.
- Pi 0.99 transitive runtime additions required by the target package are present in the lockfile, including Pi `agent-core`, `codemode`, `mcp`, `chord`, and `telemetry` `0.99.x`, plus the target provider SDK changes. The direct Pi trio is exactly `@earendil-works/pi-ai`, `@earendil-works/pi-coding-agent`, and `@earendil-works/pi-tui` `0.99.0`; transitive `@earendil-works/pi-telemetry` resolves to `0.99.1` because the upstream package declares `^0.99.0`, and is not a direct repository dependency. TypeScript `6.0.3`, Node typings, Tailwind, Glimpse, Monaco, Husky, TypeBox, and other unrelated direct ranges remain unchanged.
- Published workspaces continue to keep host-provided modules in `peerDependencies` with `"*"` ranges and do not bundle them. The baseline found three existing omissions and added only the necessary `@earendil-works/pi-ai: "*"` peer to `code-reviewer`, `librarian`, and `triage-comments`; each imports the shared `Usage` type. No runtime behavior was changed.
- No shared TypeScript/load adaptation was needed: `npm run typecheck`, direct entry imports, and packaged runtime loading pass on Pi 0.99. Specialized provider/auth, safety/nested-tool, context/routing, and subagent behavior remain in their owning tickets below.
- Standalone `claude-fast` and `openai-fast` remain represented and unchanged. New Fast capabilities are not added to either retired standalone package; the active unified `fast` workspace remains the only target for future Fast behavior.
