# Announcement drafts — v0.1.66

## Short

Pi Extensions v0.1.66 certifies all 28 packages against Pi 0.84.4, including explicit Pi 0.84.3 runtime coverage. `permission-gate` now conservatively protects Pi's PowerShell tool with native Windows AST analysis, Oracle and Contrarian are synchronized to the current provider catalog, and `/annotate-git-diff` now ships a no-CDN Tailwind/Monaco runtime that works in normal Node Pi and official SEA builds from both root and standalone package layouts. The annotation commands also gain race-safe native-window startup, failure buffering, normal submit/cancel closure, and complete server/watcher cleanup.
