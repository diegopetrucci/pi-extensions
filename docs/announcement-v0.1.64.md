# Announcement drafts — v0.1.64

## Short

Notify now forwards OSC 777 and OSC 99 terminal notifications through tmux's DCS passthrough when `$TMUX` is set. Add `set -g allow-passthrough all` to `tmux.conf`; use `terminal.tmuxPassthrough` to choose `auto`, `always`, or `never`.

## Packages

- `@diegopetrucci/pi-notify@0.1.16`
- `@diegopetrucci/pi-extensions@0.1.64`
