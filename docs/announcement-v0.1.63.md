# Announcement drafts — v0.1.63

## Short

Pi Extensions v0.1.63 adds one `/fast` toggle for supported OpenAI Codex and Anthropic Claude models. It follows the selected model automatically, while the original provider-specific packages remain available standalone. The release also includes the latest Dynamic Context Pruning filtering, agent-state detection, and benchmark improvements.

## Packages

- `@diegopetrucci/pi-claude-fast@0.1.13`
- `@diegopetrucci/pi-fast@0.1.0`
- `@diegopetrucci/pi-openai-fast@0.1.15`
- `pi-dynamic-context-pruning@0.1.6`
- `@diegopetrucci/pi-extensions@0.1.63`
