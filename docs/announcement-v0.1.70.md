# Announcement drafts — v0.1.70

## Short

Pi Extensions v0.1.70 fixes Minimal Footer's OpenAI Codex usage labels. Usage windows are now labeled from the durations OpenAI reports, so an account with only a weekly primary window shows `7d` instead of an assumed `5h`. Explicit label overrides remain supported, and unknown durations use neutral labels rather than positional guesses.
