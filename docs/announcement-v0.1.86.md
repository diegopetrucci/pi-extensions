# Announcement drafts — v0.1.86

## Short

Draft for publication only after successful release verification:

pi-extensions v0.1.86 adds the newly documented Fast and Ultrafast models to `/fast`, and drops Claude Opus 4.8 ahead of its Fast deprecation:
- GPT-6.1 Terra on Codex and the API
- GPT-5.6 Sol on the API
- Claude Fable 5.2 and Mythos 5.2
- Ultrafast on GPT-6.1 Sol

It also makes `dynamic-context-pruning` more accurate and fixes bugs in `oracle`, `contrarian`, `annotate-git-diff`, and `inline-bash`. Thanks to @chenxin-yan for the Fable 5.2 contribution. `pi install npm:@diegopetrucci/pi-extensions`

Suggested public title: **More Fast-mode models, plus context-pruning and annotation fixes**.

This is an unpublished candidate. Do not post this announcement until the protected OIDC workflow succeeds and post-publication verification is complete.
