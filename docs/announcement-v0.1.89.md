# Announcement drafts — v0.1.89

## Short

Draft for publication only after successful release verification:

pi-extensions v0.1.89 adds Pi 1.7.0 development compatibility and permission-aware approval dialogs:
- `permission-gate`, `dirty-repo-guard`, and `confirm-destructive` report approval prompts as permission requests in terminals with program status
- `oracle`, `contrarian`, and `code-reviewer` refresh their model ladders for the Pi 1.7.0 catalog, including Qwen4 Max, `glm-5.4`, and restored `ant-ling`
- `context-inspector` matches Pi 1.7.0 bash truncation notes and shows why full output could not be saved
- `illustrations-to-explain-things` hardens its codemode image fallback

`pi install npm:@diegopetrucci/pi-extensions`

Suggested public title: **Pi 1.7.0 compatibility and permission-aware approval dialogs**.

This is an unpublished candidate. Do not post this announcement until the protected OIDC workflow succeeds and post-publication verification is complete.
