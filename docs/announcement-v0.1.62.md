# Announcement drafts — v0.1.62

## Short

Pi Extensions v0.1.62 certifies the full package fleet against Pi 0.83.0. Oracle, Contrarian, Code Reviewer, and Librarian now keep automatic model selection and fallbacks inside a non-empty session model scope, while explicit model choices remain authoritative. The release also removes stale Fireworks GLM 5.1 preferences and updates all 27 compatibility markers.
