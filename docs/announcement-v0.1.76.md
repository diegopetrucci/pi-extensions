# Announcement drafts — v0.1.76

## Short

pi-extensions v0.1.76: the collection now ships `/ultrafast` and the new `project-mcp-json` extension (Claude Code-style `.mcp.json` in trusted folders), plus fixes for `git-footer` in untrusted projects, literal `inline-bash` output, Oracle/Contrarian model fallback, and quieter `gnosis` errors. `pi install npm:@diegopetrucci/pi-extensions`
