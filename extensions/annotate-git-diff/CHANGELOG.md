# Changelog

Notable user-facing changes to this package are listed here, newest first.

## [0.1.18] - 2026-11-17

- git commands now time out after 30s and clipboard commands after 5s, instead of hanging Pi.
- A git timeout now fails the review with a timeout error instead of looking like an empty diff.
- First release to ship a package changelog, so Pi 1.5.0+ shows release notes after an update.
