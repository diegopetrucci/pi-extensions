# Changelog

Notable user-facing changes to this package are listed here, newest first.

## [0.1.16] - 2026-11-27

- The fork confirmation prompt now reports as a permission request (`blockedKind: "permission"`) so terminals with program status can show it as such; Pi older than 1.6.1 ignores the field. Other prompts are unchanged.

## [0.1.15] - 2026-11-17

- First release to ship a package changelog, so Pi 1.5.0+ shows release notes after an update.
